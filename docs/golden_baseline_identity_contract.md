# Golden Baseline Identity Contract

A Golden candidate must link one immutable source snapshot, its own build and
devel artifacts, launch command/parameters, world/model/CSV inputs, and a
historical run proving A1 stability, building entry, corridor progress, and
room-zone arrival. A run summary alone, a source commit alone, or an unrelated
handoff build alone is insufficient. No mixed candidate may be launched unless
every component is explicitly evidenced and approved.
